# Orb

**Pay anyone you see on your screen.** Orb is an Android wallet with a floating orb that sits over every app. Tap it in WhatsApp, X or Telegram, say "pay this", confirm with your fingerprint, and the MON settles on Monad testnet in about a second. You never leave the app you were in.

```
┌──────────────────────────── Android phone ─────────────────────────────┐
│  Any app (WhatsApp, X…)          BubbleService (foreground service)    │
│        ▲                         └─ overlay window: draggable orb      │
│        │ reads visible text            │ tap                           │
│  ScreenReaderService ◄─captureNow()────┘                               │
│        │ ScreenContextStore (120 s)     │ bubbleagent://ask?ctx=<id>   │
│        └──────────────► Orb app (translucent) ─ tabs ─ /ask sheet      │
│                               │  Privy embedded wallet (signs locally) │
└───────────────────────────────┼────────────────────────────────────────┘
                                │ HTTPS (bearer token)
                   Agent server (Node, Hono) → Claude tool loop
                   tools: balance · inspect_address · prepare_native_transfer
                          · get_tx_status · ask_user   (read-only RPC)
```

| Path | What |
|---|---|
| `app/` | Expo SDK 53 app: `app/` routes (Wallet, Activity, Orb, Profile tabs and the `/ask` sheet), `src/` logic and components, `modules/bubble-overlay/` Kotlin module, `plugins/` config plugin |
| `server/` | Agent server, MCP server and vitest tests. See [server/README.md](server/README.md) |

## Prerequisites

- Node 20.12+, pnpm (app), npm (server), ngrok
- JDK 17 and the Android SDK (`ANDROID_HOME`), and an Android 10+ phone with USB debugging on
- A Privy app with email login and EVM embedded wallets. In its mobile client, allow the app identifier `com.bubbleagent.app` and the URL scheme `bubbleagent`.
- An Anthropic API key (optional: without it the server uses a basic offline parser)

## Run

```bash
# 1. Agent server
cd server && npm install && cp .env.example .env   # set ANTHROPIC_API_KEY and a long random AGENT_TOKEN
npm run dev

# 2. Tunnel (second terminal)
ngrok http --url=<your-domain>.ngrok-free.dev 8787

# 3. App (third terminal, phone plugged in)
cd app && pnpm install && cp .env.example .env     # Privy IDs, ngrok URL, same AGENT_TOKEN
pnpm android
```

Release APK with no dev server: `pnpm android:release`.

`android/` is generated by `expo prebuild` and is not committed. Native changes go in `modules/bubble-overlay` and `plugins/`.

## Try it

1. Sign in with your email, then open **Wallet → Faucet** to get testnet MON.
2. On the **Orb** tab, grant the permissions in Setup and turn the orb on. Leave the app.
3. In any app, show `dinner was 0.2 MON, send to 0x<address>` and tap the orb.
4. Tap **Pay this**, review the payment, then **Confirm** with your fingerprint. The card shows **Confirmed in N ms**.

Also try "My balance", "What is this address?", two addresses on screen (you pick one), and stopping the server (the basic parser still prepares the payment).

## Permissions

| Permission | Why |
|---|---|
| Display over other apps | Draws the orb. Required. |
| Accessibility ("Orb screen reader") | Reads visible text only at the moment you tap the orb. Without it, use the clipboard. |
| Notifications (Android 13+) | The notification that keeps the orb running. |
| Battery optimisation exemption | Stops the system from killing the orb. |

If you sideloaded the APK, enable accessibility via App info → ⋮ → **Allow restricted settings**. On Xiaomi, Oppo, Vivo and Realme phones, also enable **Autostart** and **Display pop-up windows while running in background**.

## Security

- Keys stay on the device in the Privy embedded wallet. The server only proposes payments, and the app rebuilds and re-checks every proposal before showing it.
- Every payment needs an explicit Confirm plus fingerprint or device PIN. Per-payment and daily limits (1 and 5 MON by default, 10 MON maximum) are enforced on the server and on the device.
- The recipient must appear on screen or in your message, so the model cannot introduce addresses. Screen text is treated as untrusted input.
- The screen is read only when you tap the orb. You can see and exclude the captured text, and captures live in memory for at most 120 seconds.
- Monad testnet only (chain 10143), checked by the server, the app and the wallet before signing.
- `EXPO_PUBLIC_AGENT_TOKEN` ships inside the APK, so the agent auth is demo-grade.
