10 answers

What is Orb?+

Orb is an Android wallet with a floating button over other apps. Tap it to read visible text, ask a question, check a suspicious message, or prepare a MON payment. You review and approve payments on your device.

Does Orb work with WhatsApp, email and Telegram?+

Orb reads visible text through Android accessibility when you tap it, or uses text you copy. It is not a WhatsApp, email or Telegram integration. The screens on this website are illustrative samples.

Is the website demo a real payment?+

No. Every example, address and receipt here is a local simulation. The website never connects to your wallet, signs a transaction or sends funds.

Which tokens and networks can I use?+

The current app supports native MON on Monad mainnet (chain 143) and testnet (chain 10143). Say the network explicitly; Orb asks when it is missing. ENS names resolve on Ethereum, but the payment is sent on the Monad network you choose.

What does Scam Shield check?+

It flags signals such as requests for secrets, remote access, pay-to-receive fees, urgency and lookalike recipients. It shows Looks safe, Be careful or Likely scam with reasons. These are risk signals, never a guarantee that a payment is safe.

Can an AI agent spend without asking me?+

An MCP client can request a payment and check its status. You review and explicitly approve on the phone. Agent keys can be disconnected. Preview agent limits and account binding still need production hardening; start with testnet.

How are payments approved?+

The app uses fingerprint or device PIN where supported and enrolled. If device authentication is unavailable, not enrolled or fails its capability check, the current preview uses a hold-to-confirm action. Voice never confirms a payment.

Is Orb always reading my screen?+

No. The screen reader captures visible text when you tap the orb. You can inspect or exclude the captured text. The native handoff expires after 120 seconds, but included text can remain in the Ask session and is sent to the agent server for online requests.

What does the Android download need?+

A 64-bit ARM Android 10+ phone. This v1.0.0 APK is debug signed and sideloaded, not a Play Store release. AI chat and connected agents need the configured server to be reachable. A basic parser can interpret supported requests without the agent server; chain checks and payments still need internet.

Is there an iPhone version?+

The current release is Android only. The overlay and screen-reading workflow depend on Android capabilities. There is no iOS download in this release.
