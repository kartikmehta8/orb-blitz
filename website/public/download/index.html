A preview, with a few things to know.

This is a directly installable APK, not a Play Store release. Start on Monad testnet while you explore.

AI chat, model-assisted safety checks and connected-agent notifications need the build’s configured server to be reachable. If the server is unavailable, a basic parser can interpret supported requests. Chain checks, ENS and payments still need internet.

Agent request limits and wallet ownership verification still need production hardening. Screen and recipient checks reduce risk; they do not guarantee safety.
